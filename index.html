Sanctum Desktop

Drag in a document. Review the detections. Export a clean copy. All on your machine.

These builds are unsigned

Sanctum Desktop is pre-alpha and not yet code-signed or notarized. Your operating system will object the first time you open it — that is expected, and the instructions below get you past it. These builds are for developers and testers, not for handling real confidential documents yet.

Download

  • macOS Apple Silicon · .dmg
  • Linux x86_64 · AppImage
  • Debian / Ubuntu amd64 · .deb
  • Windows Not available yet

First run

macOS

macOS will say the app is damaged or cannot be verified. It is not damaged — it is unsigned, and the download carries a quarantine flag. Drag the app to Applications, then run: 

xattr -dr com.apple.quarantine "/Applications/Sanctum Desktop.app"

Only Apple Silicon Macs are supported. There is no Intel build.

Linux

The AppImage needs to be made executable before it will run:

chmod +x Sanctum-Desktop-x86_64.AppImage
./Sanctum-Desktop-x86_64.AppImage

If it fails on missing FUSE, install the .deb instead, or extract the AppImage with --appimage-extract.

Windows

No Windows build yet — code signing is still being arranged. Without it, SmartScreen blocks the installer outright rather than merely warning about it.

Something broke

Expected, at this stage — please say so. Open an issue on the desktop repo with your OS and what you were doing.
